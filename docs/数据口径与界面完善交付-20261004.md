# 数据口径与界面完善

## 本轮修改

- 历史报名名单的年级、班级 ID、筛选和导出统一优先采用报名快照；修改常用参加人的资料不会把已有报名移到新班。旧无快照记录保留原回退规则。
- 全额退款后的原成功付款仍计入累计支付，成功退款单独累计。金额仍为整数分；统计日期仍按北京时间的团期出发日，不改成资金发生日。
- 报名步骤改为“填写资料、核对信息、支付、完成”。已付款订单突出行前入口；已退款订单保留原订单资料入口并明确退款状态。
- 后台合同团期显示学校、活动、日期和辅助编码。当前启用及最新保存版本默认可见，其他历史版本可展开；所有历史全文、启用权限和已有订单合同保持。

两项数据修复只改变查询，不迁移、不重写历史报名或金额。现有小程序未提供换班编辑界面，名单反例通过已有成员更新 API 验证。

全工作区1198项单元测试、类型检查和 lint 已通过；真实 MySQL/HTTP 最终35项通过，修复前5项失败作为回归证据保留。独立浏览器补验11项通过，五路复核与两路图审通过。LSP不可用，使用项目 TypeScript/Vue 编译检查，未新增开发依赖。
