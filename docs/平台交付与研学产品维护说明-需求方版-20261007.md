# 平台交付与研学产品维护说明

更新日期：2026年10月7日

章总、舒经理，你们好：

平台可以先交给你们查看和试用了。研学课程介绍、封面图片、团期日期、价格、招生范围等日常内容，可以按下面的步骤在后台维护。已经发布的内容保存后，家长重新进入小程序对应页面，就能读取更新，不需要每改一张图片或一段介绍都找我重新上传小程序。

这次先交付平台使用和内容维护，正式运营前，我们再一起核对首个实际团期、手机报名流程以及保险、通知等交接结果。你们在后台发布团期后，当前可使用的小程序会读取这些内容，不需要重新上传小程序。微信的“正式发布”是指把小程序从体验阶段开放给普通用户；之后日常更新介绍、图片和团期，仍然直接在后台完成。

**一、从哪里进入，账号怎么交接**

后台地址：[https://admin.linantravel.cn/](https://admin.linantravel.cn/)。建议用电脑操作，方便填写长文本和核对名单。

目前入口有一层访问验证。如果浏览器先弹出用户名、密码框，先使用我单独交接的入口验证信息；进入“管理后台登录”页面后，再用分配给操作人员的工作人员账号登录。这两组信息用途不同。

账号、临时密码和入口验证信息由我单独交接，不写在这份说明里。首次登录如果提示修改密码，按页面要求修改后再继续。你们指定实际维护人员后，我会按岗位核对权限；内容维护、财务、学校和导游分别使用对应账号。

登录后展开左侧“研学运营”，点击“活动配置”，页面标题是“学校、课程与团期配置”。合同另在“研学运营 → 团期合同”中维护。如果看不到相应菜单，先联系我核对账号权限。

**二、先分清几个内容分别在哪里维护**

| 内容 | 用来做什么 | 后台位置 |
| --- | --- | --- |
| 学校、年级、班级 | 确定报名对象及所属学校 | 活动配置 |
| 课程 | 活动名称、介绍、封面等公共介绍 | 活动配置 → 课程 |
| 共享课程模板 | 同一套介绍和封面供多个学校使用 | 活动配置 → 共享课程模板 |
| 团期 | 某所学校具体哪天出发、多少钱、多少名额、何时报名 | 活动配置 → 团期 |
| 家长告知书 | 本团期的行程、集合地点、餐食、费用说明和报名须知 | 活动配置 → 家长告知书版本 |
| 团期合同 | 家长报名后需要阅读并手写确认的合同正文 | 团期合同 |

同一个课程可以安排多个团期。新增日期或给另一所学校安排活动时，先核对课程和学校，再新建对应团期，不要直接覆盖已经产生报名的旧团期。

**三、第一次上线一个研学团，按这个顺序操作**

**1. 准备并核对学校资料。**

先查看学校、年级、班级是否已经存在；已有的直接复用，没有的再新增。名称按实际学校信息填写。课程编码和团期编码用于区分记录，应保持唯一、便于识别。

同时准备好活动名称、介绍、可使用的封面图片、出行日期、价格、人数上限、招生范围、报名时间、告知书及核准后的合同正文。

**2. 新增课程，或者维护已有课程。**

新建时在“课程”区域选择学校，填写课程编码、课程名称、课程介绍，并选择封面。

课程状态选择“启用”；后面的团期先保留“草稿”，用团期状态控制何时对外展示。单独保存课程不会自动开放报名。

封面现在可以直接操作：选择本地图片 → 等待上传 → 查看预览 → 自动填入图片地址 → 点击“新增课程”或“保存课程内容”。

支持PNG、JPEG、WebP，单张最大5MB。建议用横向图片，预览按16∶9展示，重要人物和内容尽量放在中间。使用自有或已获授权的图片。

看到“封面已上传”后，还需要保存课程。上传失败时原封面链接会保留；确认预览正确后再保存。

修改已有普通课程时，在“编辑课程内容”选择对应课程，可以修改名称、课程状态、介绍和封面，再点击“保存课程内容”。课程设为“停用”或“草稿”后，家长端不再展示该课程，已有订单保留；恢复“启用”后，已发布团期恢复展示。关联共享模板的课程内容按下一步维护。

**3. 多个学校使用同一内容时，可以使用共享课程模板。**

在“共享课程模板”中新建模板，填写名称、介绍、封面并保存；然后通过“关联学校课程”，选择学校和对应课程进行关联。各学校的价格、日期和招生范围仍然在各自团期中设置。

以后修改模板名称、介绍或封面，点击“保存共享内容”，会同步到所有已关联的学校课程。保存前先看页面显示的关联数量。

如果只想改某一所学校的内容，先点击该学校课程旁的“解除关联，保留当前内容”，再到课程编辑区修改介绍和封面。

**4. 新增团期，先保存为草稿。**

在“团期”区域依次填写：

| 字段 | 填写说明 |
| --- | --- |
| 团期学校、团期课程 | 确认属于同一所学校，避免选错同名课程 |
| 团期编码 | 使用便于区分学校、日期和批次的唯一编码 |
| 团期单价（元/人） | 填实际收费金额；当前学生、成人同价，按报名人数计费 |
| 容量 | 填允许接收的参加人数；已有团期可在“编辑团期”修改容量，不能少于保存时的已付款有效人数 |
| 最低人数参考 | 可选；它用于提醒人数是否达到参考值，不会自动成团、取消或退款 |
| 出发日期、结束日期 | 按实际行程填写 |
| 报名开始、报名截止 | 按北京时间选择日期、小时和分钟，核对截止时刻后保存 |
| 招生范围 | 选择全校，或指定年级、班级；指定范围前先配好年级和班级 |
| 团期状态 | 初次录入先选“草稿”，内容核对完成后再发布 |

点击“新增团期”，确认出现保存成功提示。

**报名开始和截止统一按北京时间填写，可以直接设置到分钟。**例如约定10月20日晚上8点半截止，就选择10月20日20:30。保存后，在团期列表或“查看该团期已保存内容”核对日期和时刻；已有团期会显示原来保存的真实时间，不会自动改成当天晚上。

后续修改日期、报名时刻、单价或容量，在“编辑团期”选择对应编码，点击“保存团期修改”；修改招生范围后，另外点击“保存招生范围”。容量须为正整数，不能少于已付款有效人数；如填写最低人数参考，也不能高于容量。保存失败时按提示调整，不要把尚未保存的数值当成已经生效。

**5. 创建并启用家长告知书。**

在“家长告知书版本”中选择刚建好的团期，填写版本号、标题、目的地、集合地点、餐食说明、行程、费用说明、组合示例和报名须知。

现有行程表单按7段录入，请填写实际安排；如果正式行程不适合这个结构，先发我核对，不要为了填满位置写入没有安排的服务。

费用说明属于展示文字，实际计费依据是团期单价。两处金额必须核对一致，修改费用文字不会自动改价。

先点击“创建告知书版本（暂不生效）”，再到下方对应团期记录中点击“启用 v1”等版本按钮。确认该团期的“生效告知书”显示正确标题和版本。

以后修改告知书，应创建新版本再启用。已经提交的订单保留报名时确认的版本，不会被新告知书覆盖。

**6. 需要家长签字的团期，另行启用合同。**

进入“研学运营 → 团期合同”，按学校、活动、日期和团期编码选中目标团期，点击“读取合同”。

在“原件范本”中选择现有范本，点击“导入范本全文”。将核准后的正文粘贴或编辑到“合同全文”中，补齐本团期的行程、费用、服务、保险及其他约定，填写合同标题、版本名称，勾选“我已核对本团期适用条款并补全正文”，再点“保存新版本”。

保存后点击“查看全文”核对，确认无误再点“启用此版本”。只有保存、没有启用，后续报名不会自动使用这份合同。

合同启用后，新建报名按“核对报名 → 阅读合同 → 同意并手写签字 → 继续支付”办理。旧订单保留原合同；启用前已经生成的无合同订单，不会自动补上合同。

目前已有团期使用的内容标注为试用模板。正式团期请先核准适用条款和空白项，再启用。在线签字记录与保险公司的投保回执、旅行社签章、监管平台备案分别办理，不能用家长签字代替这些结果。

**7. 核对完成，再发布团期。**

在团期记录的“报名条件核对”中查看课程状态、团期状态、生效告知书、报名时间和名额。再人工确认学校、招生范围、价格、日期以及本团需要的合同。

准备完成后，点击该团期的“发布”，确认状态变成“已发布”。课程启用且团期发布后，家长可以浏览；能否报名还要符合招生范围、告知书、时间和名额条件。

首次开放真实报名之前，我们一起把本团的收费、合同、保险安排和手机报名流程核对一遍。内容录入阶段先保留草稿，当前云端已接入真实收付款，不要把已发布团期当成随意练习付款的环境。

**8. 先看后台已保存内容，再到手机核对。**

保存后点击“查看该课程已保存内容”或“查看该团期已保存内容”，核对实际保存的封面、介绍、日期、价格和生效告知书。编辑区的“未生效告知书预览”用于核对草稿，不能作为已经发布成功的依据。

随后从微信打开当前可使用的小程序版本，退出原活动详情后重新进入，确认：活动和学校正确、图片正常、价格与日期一致、报名入口状态正确，告知书及应签合同版本正确。体验版查看人员需有相应体验资格；面向普通家长开放还要确认正式版本已完成微信发布。

**四、以后日常维护，哪些能自己改，哪些先联系我**

| 日常事项 | 当前办理方式 |
| --- | --- |
| 新增研学课程、团期 | 按上述流程在后台操作 |
| 修改已有普通课程名称、状态、介绍、封面 | 在“编辑课程内容”保存；家长重新进入页面后读取更新 |
| 修改共享模板名称、介绍、封面 | 在模板中保存，同步关联学校课程 |
| 修改团期单价、日期、报名时刻、容量、招生范围 | 在“编辑团期”操作；报名时间按北京时间精确到分钟，容量不得少于已付款有效人数 |
| 更新告知书、合同 | 新建版本，核对后启用；历史订单保留原版本 |
| 暂停新报名 | 点击团期“关闭”；已有活动仍可能被浏览，订单和历史记录保留 |
| 查看订单、有效名单和行前安排 | 分别进入“订单管理”“名单统计”“行前配置”，按团期及账号权限操作 |
| 页面布局、按钮逻辑、新增功能或计费规则调整 | 我这边开发、验证后更新；涉及小程序页面时另行上传版本 |

修改团期单价只用于新订单，已经生成的订单金额保持原值。若需要处理已经报名人员的差价、退款或换人，应按对应业务流程办理，不通过改团期价格代替。

关闭团期不会自动退款。已有报名和付款的团期保留历史记录，暂停时使用“关闭”，不要用删除代替退订处理。

集合地点、行程等内容在报名后发生变化，还要通知受影响的家长。保存内容本身不代表微信消息已经送达；以实际通知和家长收到的结果为准。

**五、遇到问题时先查哪里**

| 现象 | 先核对的项目 |
| --- | --- |
| 后台保存了，小程序没看到 | 是否选对学校和团期；课程是否启用；团期是否发布；是否重新进入页面 |
| 能看到活动，但不能报名 | 生效告知书、报名起止时间、剩余名额及参加人的招生范围 |
| 图片有预览，手机还是旧图片 | 是否点击了课程或模板的保存按钮；共享模板关联是否正确；重新进入详情页 |
| 合同保存了，报名没有签字 | 是否启用在正确团期；测试的是否为启用后新建的订单 |
| 模板课程在普通编辑区不能修改 | 到共享模板中维护；单校独立修改先解除关联 |
| 提示无权限或看不到菜单 | 联系我核对账号权限，不反复使用其他人的账号尝试 |

如果仍有问题，把操作时间、学校、团期编码、所在页面和错误截图发给我。截图不要包含完整身份证号、健康内容或账号密码。

**六、这次交付怎么确认**

先由你们指定一位实际维护人。我把访问方式和账号单独交接后，由这位同事本人完成登录、修改临时密码，并使用尚未对外展示的课程和草稿团期练习一次选图上传、编辑介绍、保存和查看内容。

接着选首个准备上线的真实团期，由你们确认价格、日期、容量、报名截止时间、告知书和合同内容。我们安排指定家长在受控范围核对手机登录、隐私确认、手机号授权、新报名合同签字和支付流程，再由你们决定正式开放；款项操作按事先确认的人员、金额和处理方式办理。

订阅消息及客服实收、保险公司真实回执、活动相册实际访问、首团全流程和长期运维交接，继续按各自结果逐项确认。这次交给你们查看和维护平台，不提前把这些事项写成已经全部验收完成。

以后日常介绍、图片和团期维护由你们操作；技术故障和现有页面以外的改动由我配合。账号接收人、日常维护人、财务负责人以及技术维护和资源续费联系人，在正式接管时一并明确。
