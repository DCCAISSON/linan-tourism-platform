# 微信小程序与支付正式接入清单

更新日期：2026-09-23

## 一、可以立即交付的微信资料

请把真实值写入 `private/微信小程序与支付接入.local.md`，不要发在聊天、Issue 或 Git 中。

小程序登录需要：

- 正式 AppID；
- 正式 AppSecret；
- 小程序管理员和开发者权限已生效；
- `https://api.linantravel.cn` 已加入 request 合法域名；
- `https://linantravel-test-1488582402.cos.ap-shanghai.myqcloud.com` 与 `https://linantravel-prod-1488582402.cos.ap-shanghai.myqcloud.com` 已按体验/正式环境加入 downloadFile 合法域名；
- 一个只含虚构数据的体验家庭码。

服务器最终使用：

```text
WECHAT_MINIAPP_APP_ID
WECHAT_MINIAPP_APP_SECRET
```

## 二、微信支付平台侧动作

由商户超级管理员完成：

1. 确认本项目采用普通商户直连模式；若实际采用服务商模式，需要重新确认接口字段和资金主体。
2. 在微信支付商户平台开通 JSAPI/小程序支付权限。
3. 发起小程序 AppID 与商户号的关联授权。
4. 由小程序管理员在微信公众平台确认关联。
5. 下载商户 API 证书或按商户平台要求生成商户私钥，记录证书序列号。
6. 设置 32 字节 APIv3 密钥，并取得微信支付公钥 ID/公钥或平台证书。
7. 提供一个金额可控的正式测试商品和退款测试安排。

官方资料：

- [开发接入准备](https://pay.weixin.qq.com/doc/v3/merchant/4015459512)
- [管理商户号绑定的 AppID](https://pay.weixin.qq.com/doc/v3/merchant/4013287504)
- [开发必要参数](https://pay.weixin.qq.com/doc/v3/merchant/4013070756)
- [JSAPI/小程序下单](https://pay.weixin.qq.com/doc/v3/merchant/4012791897)

## 三、服务器配置

```text
WECHAT_PAY_ENABLED=true
WECHAT_PAY_MERCHANT_MODE=direct_confirmed
WECHAT_PAY_MCH_ID=<商户号>
WECHAT_PAY_SERIAL_NO=<商户证书序列号>
WECHAT_PAY_API_V3_KEY=<32字节APIv3密钥>
WECHAT_PAY_PRIVATE_KEY_PATH=<服务器商户私钥绝对路径>
WECHAT_PAY_PUBLIC_KEY_ID=<微信支付公钥ID或平台证书序列号>
WECHAT_PAY_PUBLIC_KEY_PATH=<服务器微信支付公钥或平台证书公钥路径>
WECHAT_PAY_NOTIFY_URL=https://api.linantravel.cn/wechat/payments/callback
WECHAT_PAY_REFUND_NOTIFY_URL=https://api.linantravel.cn/wechat/refunds/callback
```

私钥文件权限设为仅运行账号可读。APIv3 密钥、私钥、AppSecret 不写入前端构建，不记录到日志。

## 四、联调顺序

1. 真机微信登录并完成家庭码首次绑定。
2. 创建一笔最低可用测试订单，核对金额单位为分。
3. 调起微信支付，核对付款人、商户名、金额和订单号。
4. 验证支付回调签名、重复回调幂等和订单状态。
5. 按取消人员计算退款金额，提交一笔退款并验证退款回调。
6. 核对支付账单、退款账单和平台订单三方差异。
7. 验证支付失败、用户取消、退款处理中和退款失败状态。
8. 完成后再将体验版提交审核；正式发布由小程序管理员最终操作。

## 五、当前程序边界

代码已具备小程序下单、签名、支付回调验签与解密、退款、退款回调和账单对账接口。未写入上述真实参数时，生产环境保持关闭并明确报“微信服务尚未配置”，不会回退到模拟资金流程。
