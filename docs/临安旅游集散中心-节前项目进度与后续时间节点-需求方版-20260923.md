# 临安旅游集散中心数字化平台

## 节前项目进度与后续时间节点说明

**汇报日期：** 2026年9月23日
**汇报对象：** 杭州临安旅游集散中心有限公司
**项目阶段：** 云端可演示开发版、节前集中反馈阶段

> 本说明按截至2026年9月23日的实际进展整理。当前目标是节前完成开发版演示、记录具体差异并确定节后优先级；正式生产上线仍需完成微信平台授权、业务口径确认、公安联网备案及第三方服务接入。

## 一、总体进度

项目已经从本地原型进入云端可演示阶段。工作人员管理后台已通过 HTTPS 域名开放受保护的测试入口，小程序主要页面已在微信开发者工具中完成真实页面验收，测试数据库、文件存储和服务器部署链路已经打通。

目前已经可以围绕一条完整演示链路开展需求方点选：活动及团期配置 → 家庭多人报名 → 订单金额核对 → 模拟支付 → 工作人员名单查询与导出 → 按取消人数申请退款 → 车辆与行前安排 → 导游执行、保险、评价及通知记录。

退款暂按已确认口径处理：**按取消人数计算，不按提前天数扣费**。示例价格为128元/人，两人合计256元；取消一人时模拟退款128元。演示环境不发生真实收款或真实退款。

## 六、建议演示流程

建议本轮需求方演示控制在60—90分钟，并按同一条业务链路核对：

1. 主管理员登录，创建一个子账号并勾选权限。
2. 查看活动、课程、学校价格和团期。
3. 演示一个家庭两人报名：128元/人，合计256元。
4. 完成提交核对和模拟支付，在后台查看订单与已付款人员。
5. 按团期、学校、年级和班级查询名单并导出Excel。
6. 由家长提交取消一人的退款申请，后台核对模拟退款128元。
7. 查看统一出行名单、逐人车辆安排和行前配置。
8. 查看导游执行、健康授权、保险、评价、反馈、影像和通知页面。
9. 当场记录字段、流程、权限和报表差异，不在演示过程中临时扩展未讨论的新业务范围。

管理后台可直接通过公网受保护入口演示。小程序当前建议通过微信开发者工具或开发预览演示；在管理员完成上传权限和版本管理授权后，再上传体验版供需求方手机点选。

## 七、本阶段确认口径

- 节前目标是交付一版可点选、可反馈、可持续修改的开发版，并形成明确差异清单。
- 当前演示数据为测试数据，支付与退款为模拟流程，不发生真实资金结算。
- 已确认的核心业务框架已经进入系统；需求方现行表格、报告格式和岗位操作细节将在演示反馈后继续校准。
- 正式上线和最终验收应在微信真实授权、支付回调、业务模板、公安联网备案及第三方服务接入完成后进行。
