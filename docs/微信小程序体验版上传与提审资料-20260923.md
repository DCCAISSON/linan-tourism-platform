# 临安旅游通小程序体验版上传与提审资料

更新日期：2026-09-23

## 当前结论

小程序 AppID 已写入项目，基础信息、类目、开发者、小程序备案和微信认证已完成。`0.3.0` 生产构建已于 2026-09-23 上传为开发版本；手机端登录还需要配置正式 AppSecret、放行服务器域名，并在微信公众平台将该开发版本设为体验版。

本轮体验版本建议：

- 版本号：`0.3.0`
- 项目路径：`apps/miniapp/dist/build/mp-weixin`
- 版本说明：`需求方体验版：活动浏览、家庭报名、订单、退款申请、行前服务、通知授权、反馈与活动影像入口；真实支付暂未启用。`
- AppID：以 `apps/miniapp/src/manifest.json` 为准，不在本文重复密钥信息。

## 上传前平台设置

1. 微信公众平台“开发管理 → 开发设置”中，将 `https://api.linantravel.cn` 加入 **request 合法域名**。
2. 将 `https://linantravel-test-1488582402.cos.ap-shanghai.myqcloud.com` 加入体验版 **downloadFile 合法域名**；正式切换时再加入 `https://linantravel-prod-1488582402.cos.ap-shanghai.myqcloud.com`。这些域名用于加载后台发布的短期签名照片和视频。
3. 服务器配置 `WECHAT_MINIAPP_APP_ID` 和 `WECHAT_MINIAPP_APP_SECRET`，真实值只放服务器环境文件。
4. API 公网入口取消 Nginx Basic Auth，同时将服务切换到 `NODE_ENV=production`，避免开发身份头在公网生效。
5. 微信支付未完成授权前保持 `VITE_WECHAT_PAY_ENABLED=false` 和 `WECHAT_PAY_ENABLED=false`。
6. 准备一个只含虚构人员的体验家庭码，写入私密交接文件，不放在提审公开说明中。

微信登录使用 `wx.login` 获得一次性 code，由服务端调用 code2Session；AppSecret 不进入小程序代码。官方说明：

- [小程序登录流程](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)
- [code2Session](https://developers.weixin.qq.com/miniprogram/dev/OpenApiDoc/user-login/code2Session.html)
- [开发者工具命令行](https://developers.weixin.qq.com/miniprogram/dev/devtools/cli.html)

## 本地生产构建

PowerShell：

```powershell
$env:VITE_API_BASE_URL='https://api.linantravel.cn'
$env:VITE_WECHAT_LOGIN_ENABLED='true'
$env:VITE_WECHAT_PAY_ENABLED='false'
corepack pnpm --filter @linan/miniapp build:mp-weixin
```

构建后核对：

- `project.config.json` 中 AppID 与微信公众平台一致；
- 代码内 API 地址为 `https://api.linantravel.cn`；
- 体验版首次打开进入微信身份确认；未绑定用户可输入体验家庭码；
- 活动相册中的站内照片和视频使用 15 分钟短期签名地址，不公开 COS 永久读权限；
- 付款按钮明确显示未启用真实支付，不产生扣款；
- 实际请求不携带开发家庭身份值，构建产物不包含 AppSecret、商户密钥或真实人员资料。

## 体验版上传

开发者工具命令行示例：

```powershell
& $env:WECHAT_DEVTOOLS_CLI upload `
  --project 'apps/miniapp/dist/build/mp-weixin' `
  --version '0.3.0' `
  --desc '需求方体验版：活动、报名、订单与行前服务；真实支付未启用'
```

上传成功后，在微信公众平台“版本管理”中将该开发版本设为体验版，并添加需求方微信号为体验成员。此操作只形成体验版本，不直接提交审核或发布。

## 提审功能说明

建议填写：

> 临安旅游通用于研学活动展示、家庭成员报名、订单查询、行前服务、退款申请、服务反馈和活动影像入口。工作人员通过独立管理后台维护活动、名单、车辆、保险和执行记录。体验账号使用虚构测试数据，真实微信支付暂未启用。

建议体验路径：

1. 首次打开，使用体验家庭码绑定微信。
2. 首页查看活动，进入活动详情。
3. 选择团期和家庭成员，提交报名并生成订单。
4. 在“我的订单”查看人员、金额与状态。
5. 查看退款申请、行前服务、通知授权、反馈和活动影像入口。
