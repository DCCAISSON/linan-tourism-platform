## 可直接填写的功能说明

> 临安旅游通提供研学活动浏览、团期与参加人员选择、报名、微信支付、订单查询、按参加人申请退款、行前服务和服务反馈。用户通过微信确认身份后办理报名和查询个人订单，可在“我的→消息订阅”自主选择活动通知，并停止接收。

审核体验路径：

1. 首页或“研学活动”浏览活动，进入活动详情，查看团期、费用及报名信息。
2. 点击报名，按页面提示确认微信身份，选择参加人员并填写报名资料；健康补充为可选，单独同意后提交。
3. 提交报名后，在“我的订单”查看人员、金额、状态和支付入口；关闭微信付款层后应仍为待支付。审核查看无需再次实付测试款。
4. 已支付且符合退款条件的本人订单可进入“申请退款”，选择参加人并查看申请金额；退款需后台审核。无此类订单时，不虚构审核账号或退款记录。
5. “我的→消息订阅”查看通知类型与授权入口；订单详情查看行前服务和服务反馈。通知实际接收需本人手机授权后验证。

使用微信身份确认，不提供虚构的账号密码。运营方应选定审核期间可访问的活动及团期，并准备不含真实学生资料的测试说明；尚未指定具体活动，不在本文编造名称或编号。

图片直播当前仅有入口准备，喔图账号和真实活动直播链接尚未提供，未购买、未接通，不写入已可体验的功能。保险当前支持名单导出和人工交接记录，不宣称已自动投保或自动退保。

- **隐私声明**：核对微信公众平台实际配置的《用户隐私保护指引》及应用内文本。当前报名涉及姓名、手机号、身份证及学籍信息，可选健康信息；报名草稿还在同设备本地保存相关输入。声明需如实说明用途、保存与清除方式、健康单独同意、撤回路径、员工可见范围，以及涉及未成年人的监护同意。现有代码或文案不能证明平台声明已配置准确，当前状态待运营方核对。
- **图片直播与保险**：若本次开放喔图入口，需先提供喔图账号、活动直播链接及其接入所需域名和隐私资料，并验证可访问；否则保留未配置状态。保险方需提供接收名单的模板、必填字段及交接方式，才能验收实际交接。

保留的手机核验仅四项：

|核验项|实际操作与完成标准|
|---|---|
|报名与草稿|输入虚构资料，退出重进核对草稿及协议重新勾选；核对健康信息可选和撤回入口。|
|取消支付与退款页面|在待支付订单关闭微信付款层，确认未扣款、仍待支付且可重新进入支付；查看既有退款记录和人员状态，不再实付。真实资金退款结果已完成，手机原生页面不能由后台证据替代。|
|订阅消息|本人在“我的→消息订阅”同意需要的类型，经明确授权后发送一次联调消息并确认收到；未授权不发送。一次性订阅不代表永久推送。|
|客服|完成本人客服绑定，从活动或订单客服入口发起并实际收发；已有按钮不代表收发已验收。|
