# 2026-09-15 需求方交接清单

## 小程序

- 正式名称及2—3个备选名称；
- 简介、头像/Logo和主要服务内容；
- 最终运营主体和营业执照；
- 旅行社业务经营许可证及可能涉及的服务类目资质；
- 法定代表人、管理员的手机号和微信；
- 将开发人员添加为小程序开发者，不共享管理员密码；
- 确认小程序由谁负责长期运营、提审和版本发布。

## 腾讯云和域名

- 由最终运营主体完成腾讯云企业实名认证；
- 购买符合备案条件的大陆云资源。首期生产环境分别开通一台云服务器CVM和一个腾讯云数据库MySQL 8.4 LTS实例；两者选择同一地域、同一VPC，数据库不安装在生产云服务器内；
- 开通同地域对象存储COS，单独建立生产存储桶，用于图片、附件和导出文件；
- Cloud Studio或独立开发云服务器为可选项。本地C盘作为主开发环境时无需购买；需要云端协作或联调时再按需开通，且不得与生产服务器共用；
- 确认域名，完成企业实名；
- 通过CAM子账号授予域名、DNS、服务器、备案、SSL、COS和日志所需最小权限；
- 法定代表人或网站负责人配合短信、人脸和电话核验；
- 明确账单联系人、续费责任和到期提醒。

## 微信支付

- 商户主体和实际收款主体；
- 商户号申请资料及结算银行账户；
- 小程序AppID与商户号绑定权限；
- 超级管理员将开发人员设为技术负责人/安全联系人；
- API v3密钥、商户API私钥、微信支付公钥及公钥ID由授权人员在安全渠道配置；账户仍使用平台证书模式时再提供平台证书，均不通过聊天发送明文；
- 退款审核人、执行人和每日对账负责人。

## 核心业务资料

- 一套可验收的学校、年级、班级、课程、团期、价格和报名时间；
- 家长、参团人和紧急联系人字段；
- 是否“先审核再支付”或“支付后进入待核对”的最终流程；
- 隐私政策、监护人同意书、报名须知及版本生效日期；
- 一份完全虚构的多人报名测试数据；
- 唯一业务确认人及每日固定反馈时间。

## 当天应完成的结果

1. 名称、主体、类目和收款关系书面确认。
2. 小程序、腾讯云、域名、ICP和支付申请同步启动。
3. 开发人员获得必要的角色权限，不获得无关财务或主账号权限。
4. 三端工程开始初始化，正式名称和AppID通过配置写入。
