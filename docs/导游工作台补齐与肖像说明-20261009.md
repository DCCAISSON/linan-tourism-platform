# 导游工作台补齐与肖像说明

本轮接入小程序导游工作台的活动照片视频、学生评价和参加人日报，沿用管理后台的数据与权限。整体隐私确认增加肖像使用说明，不另弹授权窗口。

## 如何使用

从“我的 → 导游工作台”登录工作人员账号，进入已指派团期，选择以下入口。

- **活动照片视频**：填写标题，选择照片或视频并上传。照片支持 PNG、JPEG、WebP，最大10MiB；视频支持 MP4、WebM，最大50MiB。上传成功后为草稿，可预览；具备原有发布权限者可发布或下架，草稿及失败记录可删除。已发布内容进入现有家庭相册；第三方图片直播仍沿用原入口。
- **学生评价**：选择本车有效学生，按已确认标准逐人人工选择 A（优秀）或 B（合格），填写优秀／需关注标记、内部记录及各维度观察。不自动评级。已有评价按版本修订；具备确认权限者可确认全团结果，操作前明确显示全团范围。
- **参加人日报**：选择本车参加人和团期内日期，逐项记录三餐、备注和家长摘要。身体情况及私人备注只在工作人员有健康读取权限、参加人已有健康授权且当前记录允许读取时显示。已有记录更正须填写原因；可查看更正历史。摘要由具备发布权限者批准后，家长方可查看；再次保存会撤销旧批准。

页面离开后清除当前人员资料与填写内容，重新进入时读取最新权限和数据。普通导游不会因出现新入口获得评价确认或摘要发布权限。评价页面按本车筛选，后台原有团期权限范围保持不变。

## 整体隐私确认

肖像说明放在原隐私对话框中：活动照片、视频用于活动记录，并向本团参加人及其监护人展示；公开宣传另行征得同意，撤回可通过隐私保护指引中的联系方式提出。

版本更新为 `2026-10-09.1`。旧版本同意需重新确认，仍沿用原有本机版本记录；不新增后台逐人肖像授权台账。健康授权保持独立。
