# 团期保险方案与剩余需求复核

核对日期：2026年10月9日。本轮范围为团期保险方案配置、家长保障查询，以及原始需求剩余项复核。软件验证和发布结果在本文末尾分别登记。

## 后台如何维护保险方案

1. 进入“保险工作台”，选择团期。
2. 在“团期保险方案”填写保险公司、方案名称、保障内容；“投保须知”为选填。保障项目、保额、适用人群及免责条件应按正式方案填写。
3. 点击“保存保险方案”。家长从对应订单的“出行保障”查看当前拟投保方案。
4. 读取名单、生成保险批次。批次保留生成时已保存的方案；之后修改或清除当前方案，已有批次的方案及保单记录保持不变。
5. 沿用现有名单导出、登记送交、登记人工结果流程。取得保险公司实际回执后，再填写保单号和保障起止日期、登记结果。
6. 在“批次人员”上方展开“查看本批次保险方案”，核对本批次实际保存的内容。旧批次没有记录方案时，显示未记录，不套用当前方案。

具备保险查看权限的账号可以查看；具备保险填写权限且在团期授权范围内的账号才可保存。读取失败可重试；保存失败保留已填内容。切换团期后，上一团期的迟到结果不会填入新团期。

## 家长如何查看

进入“我的订单 → 订单详情 → 出行保障”。页面分为当前拟投保方案、参加人办理记录两部分，只返回当前家庭该订单的参加人。

- 每位参加人的办理记录按最近记录在前排列；新建待送交批次不会遮住旧保单。
- 待送交、待核对、办理中、已登记保单、办理未完成和退保处理中分别显示。
- 保单号及保障起止日期取自实际登记结果；未登记则明确显示未登记，不以出团日期代替。
- 方案较长时可展开阅读；历史记录展示当时的方案，当前拟投保方案单独展示。
- 报名退款与保险处理分别显示。订单退款不自动表示退保完成，批次变更也不表示每位参加人都已退保。
- 页面离开后清空当前可见数据，返回时重新读取。请求失败显示重试，不当作没有记录。

本轮未连接保险公司的自动出单或自动退保接口。保存方案、签署旅游合同、导出或送交名单均不能代替保险公司的承保回执。
