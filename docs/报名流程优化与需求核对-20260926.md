# 报名流程优化与需求核对

核对日期：2026年9月26日。

本次依据《一体化业务系统详细需求整理与确认稿》《定制开发与技术服务合同会议最终修订版》、需求方返回的流程及名单资料，以及“我们的预期前端”参考界面调整。合同仍须逐项验收，不能将已有菜单或模拟流程视为全部交付。

## 本轮调整

1. 打开小程序即可浏览活动，不要求家庭码、手机号或孩子资料。
2. 点击报名后说明信息用途，家长主动同意，再关联微信身份。家长无需另设账号密码。
3. 报名时填写参加人。姓名和证件等必填项标星；学生共用本次家长联系电话，成人可填写自己的电话。
4. 本次新参加人可删除，常用人员可取消选择。保存为常用参加人由家长主动勾选；未保存不影响订单记录留存。
5. 展示团期实际告知书的标题、版本和正文；更换团期或版本后需重新同意。
6. 微信会话过期后重新登录可找回自己的订单。手填手机号和家庭代码不能认领他人资料。
7. 后台订单展示本次联系人及紧急联系人；新报名保存当时的年级、班级，避免常用资料变化影响历史名单。
8. 空班级的无效导入行不入库。网络异常后重复保存相同参加人、重复创建同一报名的订单时，保留对应记录而不重复创建。

已上传但尚未完成报名的本次参加人，界面允许移除重新填写；常用人员按所属学校展示，跨学校分别报名。旧数据没有历史班级ID的，不凭空推算补填。

## 需求方本轮可反馈的内容

- 从学校活动入口进入后，是否能直接理解活动内容、价格和报名截止时间。
- 添加两个孩子或孩子加成人时，必填提示、删除和常用人员选择是否清晰。
- 联系人、实际随行成人、紧急联系人是否符合日常业务。
- 后台按团期、学校和班级查看的人员、联系方式及金额是否符合原有表格口径。
- 对告知书、保险名单、导游执行表和评价报告，提供修改后的正式样例及最终确认人。

后台账号继续使用已交付账号。本轮不重置密码，不以清空历史记录的方式演示流程。
