# 图片直播服务商定选与接入准备

更新日期：2026-09-23

## 定选结论

本项目将 **PhotoPlus（谱时）作为首选采购对象**，先采用“服务商私密相册 + 小程序嵌入链接”的轻接入。原因是现阶段系统已经具备按团期配置第三方相册入口，谱时公开资料同时覆盖小程序嵌入和多种私密访问方式，能较快形成可用闭环。

**Alltuu（喔图）保留为深度 API 备选。** 它公开说明支持照片直播数据 API，但其小程序嵌入说明同时列出部分能力在嵌入场景下不可用，包括人脸访问和白名单访问，因此不作为当前轻接入默认项。

## 采购时让服务商书面确认

1. 账号、相册、数据和发票主体归需求方公司所有，不挂摄影师个人账号。
2. 当前套餐支持嵌入“临安旅游通”，并明确需要添加的业务域名和校验文件流程。
3. 密码、申请后访问或等效私密访问能在小程序嵌入场景使用。
4. 未成年人照片、人脸数据、手机号和访问记录的保存周期、删除方式及服务商责任。
5. 原图、压缩图和访问数据是否可导出；活动结束后是否可批量删除。
6. 活动当天服务保障、容量、并发、照片数量、技术响应和发票信息。
7. 提供测试账号、测试相册、嵌入链接和一名技术联系人。

## 接入步骤

1. 需求方采购账号并创建一个只含授权测试照片的私密相册。
2. 微信公众平台下载业务域名校验文件，按服务商要求完成域名验证。
3. 服务商提供可嵌入的 HTTPS 链接和业务域名；将该域名加入微信公众平台“小程序业务域名”。
4. 工作人员在后台“活动影像”中选择团期，填写“PhotoPlus 活动相册”、链接并启用。
5. 家庭端已付款订单显示“查看活动影像”，进入后显示已发布的自有素材和第三方相册入口。
6. 真机验证访问控制、返回路径、分享边界、下载权限和未授权用户表现。

## 系统当前状态

- 后台已支持按团期维护相册/直播入口、启停和版本冲突检查。
- 小程序已支持从订单活动影像页打开已启用的 HTTPS 第三方相册或直播页面。
- 自有图片和视频可存入 COS，经过工作人员发布后给对应家庭查看。
- 采购前不写服务商密钥；轻接入只需要相册链接。若后续采购 API，再增加相册创建、名单同步和回调处理。
