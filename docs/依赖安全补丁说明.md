# 依赖安全补丁说明

核验日期：2026-10-07（保留2026-10-04的 braces 验收记录）。适用于本仓库的 pnpm 12.4.1 锁文件和 CI，不代表运行中的服务器已经更新依赖。

## 已发布修复版本

`brace-expansion` 的 1.x、2.x、5.x 分别固定为 1.1.20、2.1.6、5.0.11，保留原主版本。1.x/2.x 经 ExcelJS 的归档、文件匹配依赖引入；5.x 经 Nest CLI 引入。

依据：[GHSA-qhr7-859c-m2p7](https://github.com/advisories/GHSA-qhr7-859c-m2p7)、[GHSA-6j4f-fj2g-mc7p](https://github.com/advisories/GHSA-6j4f-fj2g-mc7p)。安装前，三个版本的重复嵌套/逗号组输入均已复现 `Maximum call stack size exceeded`。

2026-10-07新增两项官方补丁版本固定：

- `proxy-addr@2.0.8` 修复 IPv4 映射 IPv6 信任网段错误匹配，依据 [GHSA-jqcg-44mw-7w3h](https://github.com/advisories/GHSA-jqcg-44mw-7w3h) 和 [官方2.0.8发布](https://github.com/jshttp/proxy-addr/releases/tag/v2.0.8)。原2.0.7实测将 `203.0.113.10` 错误判为 `::ffff:10.0.0.0/8`、`::/1` 的可信客户端。
- `source-map-js@1.2.2` 修复索引映射偏移量造成的拒绝服务，依据 [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) 和 [官方修复cf76580](https://github.com/7rulnik/source-map-js/commit/cf76580)。原1.2.1实测接受 `offset.line=1e12`；回归只调用构造器验证拒绝，不实际执行会长时间阻塞的转换。

## braces 的临时本地补丁

[GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) 对 `braces <=3.0.3` 报告递归栈溢出。截至核验日，npm 最新版本仍是 3.0.3，官方公告没有已发布修复版本。[上游问题 #70](https://github.com/micromatch/braces/issues/70) 建议限制嵌套深度；[修复 PR #72](https://github.com/micromatch/braces/pull/72) 仍未合并。

本仓库通过 `patches/braces@3.0.3.patch` 对发布版增加固定 100 层上限：

- `parse` 对花括号和圆括号的嵌套计数，不把转义、引号或字符集内的字面量当作嵌套。
- `compile`、`expand`、`stringify` 对直接传入的 AST 同样限制递归深度。
- 超限抛出明确的 `SyntaxError`，不再走到原生堆栈耗尽；保留原 `stringify` 的父节点和转义语义。

这是本仓库维护的缓解补丁，不冒充上游正式修复，也不更名包或伪造版本。它覆盖本公告所述嵌套深度问题，不声称解决任意手工循环 AST、展开结果数量或所有拒绝服务输入。

## Vue SSR 的精确版本回移补丁

[GHSA-g2v6-rqmx-r4w6](https://github.com/advisories/GHSA-g2v6-rqmx-r4w6) 说明 `@vue/server-renderer<3.5.42` 的属性名校验漏掉回车（U+000D）。[官方修复a2b40db](https://github.com/vuejs/core/commit/a2b40db) 仅在 `@vue/shared` 的 `unsafeAttrCharRE` 增加 `\u000d`；本仓库把该修改精确回移到：

- `patches/@vue__shared@3.4.21.patch`
- `patches/@vue__shared@3.5.22.patch`
- `patches/@vue__server-renderer@3.4.21.patch`
- `patches/@vue__server-renderer@3.5.22.patch`

两份shared补丁只修改 CJS 开发、CJS 生产、ESM 三种发布产物中的这一行正则；两份renderer补丁修改独立 `esm-browser.js` 和 `esm-browser.prod.js` 内嵌的同一正则，每个文件仅增加 `\u000d`。生产文件为单行压缩产物，补丁的整行差异仍只有这6个字符，不重新打包。小程序 Vue / renderer / shared 均保持3.4.21，后台均保持3.5.22，不升级 uni，不修改版本号或放宽严格 peer 检查。两版本的CJS开发、CJS生产、ESM bundler、独立browser开发和独立browser生产入口均已执行真实 `ssrRenderAttrs` 与 `renderToString` 回归，补丁后不再输出 `x\rautofocus\ronfocus` 注入属性。

这是本仓库对该公告的代码回移，不代表3.4.21或3.5.22已成为上游修复版本，也不声称替代其他HTML输入边界。正常属性、属性值转义、布尔属性和属性值中的回车保持原行为。

## 按公告限定的审计例外与强制验证

`pnpm-workspace.yaml` 的 `audit.ignore` 仅列 `GHSA-vfj7-8cjw-p6xm` 和 `GHSA-g2v6-rqmx-r4w6`。每项例外均以对应本地补丁和强制回归为前提，不能单独复制到没有补丁的项目。其他公告和注册表访问错误仍须使 CI 失败，不启用 `--ignore-unfixable`、`--ignore-registry-errors` 或整类 high 放行。

CI 依次执行：

```sh
corepack pnpm install --frozen-lockfile
node --test scripts/dependency-security.test.mjs
corepack pnpm audit --prod --audit-level high
```

回归从 ExcelJS、Nest CLI、uni-app、Nest Express、小程序和后台 Vue 的实际依赖路径加载库。原有8项覆盖三条 brace-expansion 版本线、braces 的100/101层边界和4,000层攻击输入、直接AST、转义兼容、实际文件匹配及内存Excel读写。新增9项覆盖代理地址与转发头判定、恶意及嵌套索引偏移、正常映射、Vue两版本的真实SSR和三个shared发布产物；属性名覆盖CR、Tab、LF、FF、空格，正常属性与属性值另行验证。新增9项在原安装包上全部失败，冻结安装后17项全部通过；删除对应补丁后保护测试必须失败。

## 复核与移除

由维护依赖升级的开发负责人在每次正式发布前检查官方公告及npm修复版本；首次复核最迟为2026-10-11。braces正式修复发布后验证兼容性并升级；Vue已存在3.5.42正式修复，应在对应Vue / uni版本组合允许升级且验证通过时替换回移补丁。在同一变更中移除对应本地patch、`patchedDependencies`和单项`audit.ignore`。若补丁安装或强制回归失败，该项例外不可用于发布放行。
