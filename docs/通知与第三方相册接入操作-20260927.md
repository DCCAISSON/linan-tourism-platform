# 通知与第三方相册接入操作

日期：2026-09-27。本文对应本轮通知操作页及既有第三方相册 URL 接入。真实消息发送、谱时采购和真实厂商相册验收均未在本轮执行。

## 一、准备微信订阅通知

1. 小程序管理员登录[微信公众平台](https://mp.weixin.qq.com/)，在订阅消息管理中申请适用模板，审核通过后记录真实模板 ID、字段名、字段含义和微信规定的格式。字段名必须逐字对应该模板；不得照抄测试数据或其他模板的字段。
2. 将真实模板交给通知运营人员。后台“通知管理”选择团期，读取通知；填写标题、正文、真实模板 ID，以及本小程序内的页面路径。点击“添加模板字段”，逐行填写字段名和值。正文用于核对；微信实际发送内容来自模板字段。
3. 每次“创建内容版本”生成一个独立版本；刷新后可查看每个版本的实际字段值，也可沿用既有版本填写新内容。尚未取得真实模板时可以先保存正文，但这不代表已具备微信发送条件。
4. 部署人员只检查已有服务端配置是否就绪：`WECHAT_SUBSCRIBE_ENABLED`、`WECHAT_MINIAPP_APP_ID`、`WECHAT_MINIAPP_APP_SECRET`，或既有 `WECHAT_SUBSCRIBE_ACCESS_TOKEN`。服务端连接微信官方 API；任何密钥均不得填写到运营页面、前端、本文或截图中。页面只显示是否配置完成，不展示凭据。已有配置不在本轮更换。
5. 家长登录本人的已付款订单，在通知页面主动选择接收方式。微信订阅需要真实微信身份核验和本人操作订阅弹窗；人工接收方式不产生微信订阅身份。微信拒绝订阅或尚未接通时，不把付款人自动添加为微信接收人。

腾讯官方教程说明，模板应先在公众平台申请，订阅弹窗由用户点击等规定操作触发，消息字段需对应实际模板。[腾讯云：实现小程序订阅消息推送](https://cloud.tencent.com/document/product/1301/103770)。微信接口入口为[订阅授权](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/subscribe-message/wx.requestSubscribeMessage.html)；该微信文档正文在本轮抓取中未成功读取，上述操作依据已读取的腾讯官方教程。

## 二、运营人员建立任务

1. 选择有权限的团期名称，点击“读取团期通知”。页面不会要求手填团期编号。
2. 勾选本团有效授权接收人，点击“预览接收人”，逐项核对姓名、关系、渠道。没有授权时，先由家庭在订单端授权；不得代替家庭填写身份或微信 OpenID。
3. 在“内容版本”中选择已核对的版本，点击“创建任务”。系统内部生成重复提交识别键，同一次失败重试沿用原键。创建任务不发送消息。
4. 具备发送权限的工作人员核对任务和内容后，单独点击“发送待处理目标”。该动作可能真实发送消息；本轮验收不执行真实微信发送。
5. 查看目标状态及每次发送尝试。接口受理不等于送达或已读；可重试失败必须由工作人员明确点击重试。授权撤回、缺少身份、模板未配置或需人工处理时，按页面原因处理。不能把“人工处理”记成微信发送成功。

读取、创建内容/任务、发送分别使用 `notifications.read`、`notifications.write`、`notifications.send`。收件人选项不返回 OpenID；建任务和发送时继续核对授权及所属团期。授权变更后重新预览，不通过重复点击旧任务绕过撤回状态。

## 三、谱时相册的实际接入步骤

沿用 **PhotoPlus（谱时）首选、第三方私密相册加嵌入链接** 的既定方案。官方当前说明列出的支持条件为标准版及以上相应包年版本；具体账户权益和报价由业务人员向谱时确认，本轮没有采购。[谱时：智能云相册嵌入小程序](https://help.photoplus.cn/docs/1656648)。

1. 小程序管理员进入微信公众平台“开发管理 → 开发设置 → 业务域名 → 修改”，下载域名校验文件。
2. 在[谱时工作台](https://desk.photoplus.cn/)创建或找到对应活动相册，复制相册码；把相册码和校验文件提供给谱时工作人员，由其技术人员配置并返回**嵌入域名与嵌入链接**。这些是谱时官方列出的接入步骤，项目没有自建相册创建 API。
3. 将谱时返回的嵌入域名完成小程序**业务域名**配置；核对实际网页跳转涉及的域名。业务域名供 `web-view` 打开网页使用，与本系统 API 的 **request 合法域名**用途不同，不能仅添加 request 域名就认为相册可打开。最终以微信开发设置及真机域名校验结果为准。
4. 在谱时工作台“相册管理 → 相册配置 → 权限设置”选择适合该团的私密访问方式。官方支持密码和申请审核等方式；采用申请后访问时，还需配置消息通知，并由有权人员处理访问申请。[谱时：相册私密访问设置](https://help.photoplus.cn/docs/1613504)。本轮不新增人脸识别或上传个人照片。
5. 本系统后台“影像管理”选择对应团期，点击“读取素材”，在“图片直播 / 外部相册”中填写名称和谱时正式提供的 HTTPS 嵌入链接，勾选启用并保存。不得填写带用户名、密码的 URL，不使用未经确认的示例地址开展真实活动。
6. 家长从自己的已付款订单进入“活动相册”，点击相册入口。系统打开网页前重新核对订单权限和当前启用状态。网页页签退出时清除旧链接，返回时重新查询；已停用则不再打开。
7. 停用时取消“启用”并保存；家庭端重新读取后不列出该入口。停用本系统入口不撤销谱时服务器已有 URL 的访问权限，必要时同时在谱时关闭、调整访问审核或更换访问凭据。
