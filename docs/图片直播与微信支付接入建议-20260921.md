# 图片直播与微信支付接入建议

更新日期：2026-09-21

## 结论

本阶段建议先选定图片直播服务商，但不购买、不授权、不接入正式接口。开发侧先保留“图片直播入口配置位”和“本地模拟支付/退款”，等需求方确认服务商合同、未成年人照片与人脸数据条款、账号归属、测试账号后再做正式接入。

图片直播推荐顺序：

| 选择 | 适用判断 | 原因 |
| --- | --- | --- |
| 首选：PhotoPlus（谱时） | 需要嵌入小程序、相册访问控制、儿童研学活动私密观看 | 官方文档明确支持小程序嵌入，并支持密码、申请后访问、人脸识别、信息采集后访问等私密访问方式。 |
| 备选：Alltuu（喔图） | 需求方要求合同中明确开放 API，或需要把图片直播数据深度接到自有业务系统 | 官方文档说明支持自有平台、小程序绑定、照片直播数据 API、设置端/上传端/观看端等开放接口。 |
| 第三比较：XXPie（享像派） | 需求方已有摄影团队熟悉享像派，主要诉求是微信小程序分享与相册运营 | 官方帮助中心有小程序配置、照片直播、团队协作、相册设置等资料，但本次核验到的公开资料里，API 合同信息不如喔图直接。 |

## 已核验的官方事实

### PhotoPlus（谱时）

- 支持嵌入小程序：官方说明“标准版包年以上版本均支持”，流程包括在微信公众平台下载业务域名校验文件、复制智能云相册码，并交给谱时技术配置嵌入域名和链接。
- 支持相册私密访问：官方列出直接访问、密码访问、申请后访问、人脸识别解锁访问、人脸识别私密访问、信息采集后访问等方式。
- 官方链接：
  - https://help.photoplus.cn/docs/1656648
  - https://help.photoplus.cn/docs/1613504

### Alltuu（喔图）

- 支持接入自有平台：官方说明可接入公众号、小程序、网站等自有平台，也支持 API 接入图片直播核心技术或数据。
- 支持照片直播数据 API：官方说明开放对接照片直播相册的设置端、上传端、观看端等接口。
- 支持私密设置：官方列出密码访问、人脸访问、白名单访问；白名单可单个录入或批量导入昵称、邀请码，并可导出数据。
- 官方链接：
  - https://faq.alltuu.com/04/a00d/c621
  - https://faq.alltuu.com/04/a00d/9492

### XXPie（享像派）

- 支持照片直播、小程序相关配置、相册分享、团队协作、图片上传和相册运营等流程资料。
- 本次公开资料核验到“小程序配置/分享”和大量相册运营文档；如选择享像派，需要进一步向服务商确认 API、测试环境、数据导出、删除、未成年人数据处理条款。
- 官方链接：
  - https://www.xxpie.com/help/zh-CN/photolive/miniapp-setup-web.html

## 项目判断

这些判断是结合临安研学项目场景作出的，不是服务商官方承诺：

- 本项目涉及学生、家长、教师照片，优先级应是“访问可控、账号归属清晰、数据可删除、合同能约束服务商”，不是单纯看相册样式。
- PhotoPlus 更适合先作为采购默认项，因为它的公开资料直接覆盖小程序嵌入和多种私密访问方式，便于先做“嵌入入口 + 私密相册”的轻接入。
- Alltuu 更适合在需求方明确要求 API 深度集成时选择，因为其公开资料对 API 接入照片直播数据的表述更直接。
- XXPie 可以作为摄影团队偏好方案比较，但正式采用前要让服务商补齐 API、数据保护和测试资料。

## 采购前必须确认

向任一图片直播服务商采购前，建议需求方书面确认以下内容：

- 账号归属：账号、相册、数据、发票主体应归属于“杭州临安旅游集散中心有限公司”或需求方指定主体，不能挂在摄影师个人账号下。
- 未成年人数据：合同或补充协议中明确学生照片、人脸识别、家长手机号、访问记录等数据的处理目的、保存周期、删除方式和服务商责任。
- 监护人同意：如果使用人脸识别、信息采集、白名单手机号、访客上传等功能，应由需求方确认是否需要在告家长书或报名确认中增加授权文字。
- 访问权限：至少支持密码、白名单、申请后访问或同等控制；默认公开访问不适合学生研学照片。
- 数据导出与删除：明确活动结束后能否导出原图/压缩图/访问数据，能否批量删除，删除后服务商备份保留多久。
- 接入资料：提供测试账号、测试相册、嵌入链接、业务域名、API 文档、Webhook 文档、调用频率限制、错误码和沙箱说明。
- 服务保障：明确活动当天技术响应方式、SLA、现场/远程支持、相册容量、并发访问、图片数量限制。
- 财务票据：确认费用、发票类型、发票主体、服务周期、续费方式；本项目开发文档不写入任何未核实价格。

## 系统接入方式

本阶段只建议做“可配置入口”，不做真实服务商 API：

- 后台活动配置中预留图片直播配置：服务商、相册名称、嵌入链接、访问说明、是否启用。
- 小程序活动详情中显示“图片直播”入口；没有正式链接时显示“活动后开放”或隐藏。
- 若选择 PhotoPlus，优先使用服务商提供的嵌入链接和小程序业务域名配置。
- 若选择 Alltuu 且合同包含 API，再接入相册创建、名单/白名单同步、照片列表或回调通知。
- 不在本阶段保存服务商 API Key、访问令牌或真实学生照片。

## 微信支付当前授权要求

微信支付正式接入可以后置。当前系统继续使用本地模拟支付和本地退款试算，不发起真实支付、不发起真实退款。

正式接入前，需求方需要完成以下平台侧动作：

- 小程序账号完成认证。微信支付官方说明，未认证的小程序账号无法申请小程序支付权限。
- 如果已有商户号，由商户超级管理员在微信支付商户平台申请 JSAPI/小程序支付权限，并发起 AppID 授权绑定。
- 小程序管理员登录微信公众平台，在“微信支付-商户号管理”确认待关联商户号，完成 AppID 与商户号绑定。
- 商户超级管理员为技术负责人配置商户平台登录账号并设置为安全联系人。
- 交付开发必要参数到本地私密配置文件，不发聊天、不进 Git：`mchid`、`appid`、商户 API 证书私钥、证书序列号、微信支付公钥或平台证书、APIv3 密钥。
- 准备 HTTPS 回调域名。JSAPI/小程序下单接口要求 `notify_url`，用于接收支付成功回调通知。
- 小程序下单需要用户在该 AppID 下的 `openid`，订单金额单位为分，且总金额必须大于 0。

官方链接：

- 开发接入准备：https://pay.wechatpay.cn/doc/v3/merchant/4015459512
- 管理商户号绑定的 APPID 账号：https://pay.wechatpay.cn/doc/v3/merchant/4013287504
- 开发必要参数说明：https://pay.wechatpay.cn/doc/v3/merchant/4013070756
- JSAPI/小程序下单：https://pay.wechatpay.cn/doc/v3/merchant/4012791897

## 本阶段边界

- 图片直播：只做选型建议和系统预留，不采购、不授权、不接入真实 API。
- 微信支付：只保留本地模拟支付和退款金额试算，不写入真实商户密钥，不调用真实下单、回调、退款接口。
- 退款规则：正式退款、失败重试、名单移除、名额释放仍需结合皓石云现行流程和需求方最终规则确认。
