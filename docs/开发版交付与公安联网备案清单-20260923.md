## 公安联网备案提交资料

网站已经实际开通。由杭州临安旅游集散中心有限公司的负责人或网站负责人登录全国互联网安全管理服务平台提交。程序开发方可以提供服务器、域名和技术信息，主体证件、负责人实名信息、手机验证和最终提交需要由需求方完成。

建议按以下信息准备，最终以腾讯云 ICP 备案订单和公安平台表单为准：

| 字段 | 建议填写或来源 |
| --- | --- |
| 网站开办主体 | 杭州临安旅游集散中心有限公司 |
| 网站名称 | 与本次 ICP 备案中的网站名称完全一致 |
| 主域名 | `linantravel.cn` |
| 实际对外子域名 | `admin.linantravel.cn`、`api.linantravel.cn` |
| 网站 IP | `115.159.149.65` |
| 服务器地区 | 上海 |
| 接入服务商 | 腾讯云，按 ICP 备案订单中的接入商名称填写 |
| 域名注册服务商 | 腾讯云，按域名控制台中的注册商全称填写 |
| ICP 备案号 | 从腾讯云 ICP 备案订单复制完整编号，不自行简写 |
| 网站开通日期 | `2026-09-23` |
| 服务类型 | 根据公安平台选项选择单位网站/信息服务，并与实际页面功能一致 |
| 负责人资料 | 姓名、证件、手机号、办公电话和通讯地址，由需求方实名填写 |
| 数据码 | 在腾讯云 ICP 备案订单中获取；取得后应在有效期内使用 |

提交步骤：

1. 管理后台和 API 已通过域名正常打开，提交前再确认公安平台中的网站名称与 ICP 备案记录完全一致。
2. 在腾讯云 ICP 备案订单中查看“公安联网备案”数据码；若未生成数据码，仍可在公安平台手工填写。
3. 登录 [全国互联网安全管理服务平台](https://beian.mps.gov.cn)，完成主体信息和网站信息。
4. 填写接入商、域名注册商、域名、服务器 IP、服务类型和负责人信息，上传平台要求的主体资料。
5. 管理后台当前有访问保护；公安平台要求核验页面时，按表单要求提交专用审核账号，或在审核期间协调临时访问，账号密码不写入公开材料。
6. 提交审核并保存受理记录。网站已于 2026-09-23 开通，应从开通之日起 30 日内提交；若取得数据码，也应在数据码 30 日有效期内使用。
7. 审核通过后，把公安备案号、公安平台链接和备案图标补入网站页脚；同时展示完整 ICP 备案号及工信部查询链接。

腾讯云操作说明：[公安联网备案操作指南](https://cloud.tencent.com/document/product/243/120137)。
