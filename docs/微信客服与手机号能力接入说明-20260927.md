# 微信客服与手机号能力接入说明

检索日期：2026-09-27。范围：微信官方能力、公开旅游与研学流程、本项目接入建议。本文只核对公开资料，未登录平台后台、未操作账号配置、未采购，未读取项目 `private` 目录；未用真机访问所列小程序。

## 一、本项目采用的流程

首页、线路和活动详情公开浏览。游客可以先了解行程、日期、价格、报名条件和退改说明；进入报名表后可手填联系电话。保存报名时，如尚未登录，再完成必要的微信登录并继续提交，保留已经填写的内容。查看个人报名记录需要登录。

“快捷填写手机号”作为可选入口。用户拒绝授权、额度不足或接口失败时，仍能手填联系电话并完成报名。手填号码是联系信息，不能据此认定已经验证号码归属。手机号授权不用于代替微信身份识别，也不表示同意支付。

客服优先使用小程序原生客服 `button open-type="contact"`。只有运营方确实使用企业微信接待，并已完成同主体绑定时，才采用 `wx.openCustomerServiceChat`。这些是针对本项目的设计建议；下述案例不能证明所有产品都采用相同登录时点。

## 二、两种客服接入路径

| 项目 | 小程序原生客服 | 微信客服 |
| --- | --- | --- |
| 前端入口 | `button open-type="contact"` | 点击后调用 `wx.openCustomerServiceChat` |
| 会话对象 | 当前小程序的客服会话 | 指定企业 ID 下的微信客服账号 |
| 必要平台配置 | 小程序管理员在后台绑定客服人员；人员使用网页客服或移动端“客服小助手”接待 | 在微信客服管理后台取得企业 ID、客服链接；在小程序后台绑定同主体的企业 ID，并配置实际接待人员 |
| 企业微信绑定 | 原生路径不以企业 ID 绑定为前提 | 官方开发接入要求非个人主体小程序、同主体绑定；仅能打开已绑定企业 ID 下的微信客服 |
| 本项目选择 | 首选，减少额外平台配置 | 运营方已有相应接待体系时再采用 |

原生客服的 `session-from` 可以标记咨询来源；`show-message-card`、`send-message-title` 和 `send-message-path` 可帮助用户发送活动卡片。咨询入口应指向当前活动，避免让用户重复描述是哪一条线路。官方组件文档注明 `contact` 在鸿蒙 OS 暂不支持，应在实际交付设备上验证并保留已有电话联系入口。[微信 button 文档](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)

原生客服可以使用官方接待工具，无需为了人工回复另建消息服务器。若已经启用消息推送，或客服权限已授权第三方，消息会按对应配置转发，不能只添加按钮就认定客服已接通。管理员需核对现有消息去向，并用真实客服账号收发一条消息。[客服消息使用指南](https://developers.weixin.qq.com/miniprogram/introduction/custom.html)

微信客服接口必须由点击行为触发，需传入 `corpId` 和 `extInfo.url`。企业 ID、链接及同主体绑定都属于平台配置，不应使用演示值充当已开通能力。官方说明中的后台路径为“功能—客服—微信客服”，实际菜单名称以后台为准。[小程序接口](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/service-chat/wx.openCustomerServiceChat.html)、[企业微信接入说明](https://developer.work.weixin.qq.com/document/path/94739)

本次不估计企业认证、第三方客服或其他增值服务费用；是否适用及价格以对应官方后台显示为准，不列为本项目原生客服接入的采购前提。

## 三、手机号能力：条件、费用与调用方式

### 1. 已核实的条件与费用

官方当前文档说明：手机号快速验证向已认证的非个人主体小程序开放，境外主体另有地区限制；用户须主动同意。用户可选绑定号码或另行添加号码，快速验证不保证每次实时验证。[手机号快速验证组件](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)

同一官方页面列出的收费规则为：

- 自 2023-08-28 起，标准价为每次成功调用 0.03 元；套餐价格见微信公众平台“付费管理”。
- 每个小程序有 1000 次体验额度，正式版、体验版、开发版共用；先扣体验额度，再扣付费资源包。
- 额度检查发生在点击组件时，扣费发生在 `bindgetphonenumber` 成功回调时，不能按“最终报名成功次数”计算消耗。
- 免费范围包括：微信认证主体为政府或非营利组织；主体为事业单位且类目为政务民生；类目为公立医疗机构或学历教育（学校）。本项目是否符合，应核对实际账号认证主体和类目，不能因提供研学服务就推定免费。

以上价格、额度和免费条件均据[官方收费说明](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)，账号实际可用额度、套餐有效期和后续价格以后台为准。

用户提供的截图显示额度 1000、已使用 0，可作为该截图时点的账号信息。本次未登录后台复核，不据此催促购买资源包。先使用现有体验额度完成必要联调；手填联系电话继续可用。不要把额度耗尽设计成全站不能登录或不能报名。

### 2. 使用新 code 流程

1. 用户点击 `open-type="getPhoneNumber"` 按钮并同意后，前端从 `bindgetphonenumber` 获取动态 `code`。
2. 前端将该 `code` 交给本项目服务端；服务端调用 `POST https://api.weixin.qq.com/wxa/business/getuserphonenumber?access_token=ACCESS_TOKEN`，取得手机号后用于填入联系电话。
3. 手机号 `code` 有效 5 分钟，仅可使用一次。它与 `wx.login` 的登录 `code` 用途不同，不能混用；新版手机号兑换方式不要求预先调用 `wx.login`。
4. 手机号兑换接口应在服务端调用，不向小程序下发 `AppSecret` 或接口调用凭证。若本项目已取得用户 `openid`，官方接口另支持传入该值校验它与手机号 `code` 的绑定关系。

依据：[手机号组件指南](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)、[服务端获取手机号接口](https://developers.weixin.qq.com/miniprogram/dev/server/API/user-info/phone-number/api_getphonenumber)。

成功触发手机号回调后，应立即禁用或隐藏按钮，避免重复授权产生额外费用；兑换成功后显示填入的号码，让用户核对。拒绝授权时直接回到手填表单。接入前须在小程序后台的用户隐私保护指引中声明对应的信息处理，并按官方流程处理同意状态；不需要在首页先索取手机号。[button 回调说明](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)、[小程序隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)

### 3. 与登录、支付的区别

| 能力 | 解决的问题 | 本项目的边界 |
| --- | --- | --- |
| `wx.login` → 服务端 `code2Session` | 取得 OpenID 等身份标识，建立项目登录态 | 保存报名、查询个人记录时识别用户 |
| `getPhoneNumber` → 服务端兑换手机号 | 用户同意后取得平台验证过的联系电话 | 可选快捷填表，不单独决定报名归属 |
| `wx.requestPayment` | 发起微信支付 | 需要独立接入、订单及支付参数；手机号授权不构成支付授权 |

依据：[小程序登录](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)、[手机号组件](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)、[微信支付接口](https://developers.weixin.qq.com/miniprogram/dev/api/payment/wx.requestPayment.html)。

以下核验的是运营机构的公开网页及官方操作说明。公开网页可不登录阅读，不代表已验证其小程序首页无登录拦截；未真机测试，也未提交报名或付款。历史活动只用于比较流程。

## 五、接入后的必要验证

- 未登录可浏览首页、列表及详情；填写报名表后触发登录，成功后能继续原报名，取消登录不丢失表单。
- 手填有效联系电话可提交；拒绝手机号授权、额度不足或兑换失败，不影响手填路径；手机号按钮不会重复调用。
- 真机点击客服后，接待人员确实能收到消息并回复；活动来源信息正确。仅“打开成功”不足以证明接待配置完成。
- 微信登录、手机号授权、支付分别验证，不能以其中一项成功代替其余能力验收。

上述是待执行的交付检查项，本次资料研究没有执行真机或账号后台验证。
